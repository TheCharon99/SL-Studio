## 项目结构
```
dazi/
├── app.js
├── app.json
├── app.wxss
├── pages/
│   ├── index/           # 首页
│   ├── create/          # 发布

│   ├── calendar/        # 日历
│   ├── review/          # 评价
│   ├── comment/         # 评论
│   ├── favorites/       # 收藏
│   ├── settings/        # 设置
│   ├── security/        # 安全设置
│   └── feedback/        # 意见反馈
└── project.config.json
```
