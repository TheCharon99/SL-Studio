```

│   └── jquery-1.4.2.min.js
├── images/              # 图片资源
└── css/
    ├── ccslider.css     # 轮播样式
    ├── lightbox.css     # 灯箱样式
    └── media-queries.css # 响应式样式
```

### 关键设计特点
1. **布局**：960px 固定宽度，经典设计标准
2. **字体**：微软雅黑，与 wdesign.hk 完全一致
3. **配色**：
   - 背景：#ededed（浅灰）
   - 文字：#333333（深灰）、#999999（浅灰）
   - 强调：#000000（纯黑）
4. **导航**：水平菜单，当前页底部 1px 黑线高亮
5. **项目卡片**：
   - 尺寸：210×150
   - 3列网格
   - hover 效果：透明度变化 + 标题下划线
6. **轮播**：ccslider 横向滑动效果
7. **响应式**：
   - 桌面：960px 固定
   - 平板：2列网格
   - 手机：单列，select 下拉导航

## 使用说明

1. 直接在浏览器中打开 `index.html` 即可预览
2. 所有页面使用统一的 `css/yier-style.css`

4. 项目数据在 `project-detail.html` 中的 `projects` 对象
