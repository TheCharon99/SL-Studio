# YiER Studio 网站维护工作流

## 快速开始

### 添加新项目（5分钟）
```
1. 压缩图片 → TinyPNG (tinypng.com)
2. 创建文件夹 → images/项目名.jpg/
3. 复制图片 → cover.jpg + 1-7.jpg
4. 修改HTML → project-detail.html 添加数据
5. 上传 → git add . && git commit -m "" && git push
```

### 修改项目信息（2分钟）
```
1. 打开 project-detail.html
2. 搜索项目ID（如：金山豪庭-中古奶油）
3. 修改 title/area/description 等字段
4. git push
```

### 更换项目图片（3分钟）
```
1. 压缩新图片 → TinyPNG
2. 替换 images/项目名.jpg/ 中的文件
3. 保持文件名不变
4. git push
```

## 标准流程（避免重复错误）

### 阶段1：准备工作（10分钟）
- [ ] 确认用户需求，明确改动范围
- [ ] 检查现有代码结构
- [ ] 备份重要文件（git commit）

### 阶段2：本地修改（按需）
- [ ] HTML修改 → 编辑对应文件
- [ ] CSS修改 → 编辑 css/yier-style.css
- [ ] 图片替换 → 放入对应文件夹
- [ ] 脚本修改 → 编辑 js/main.js

### 阶段3：验证测试（5分钟）
- [ ] 本地预览 → 浏览器打开index.html
- [ ] 检查所有链接
- [ ] 检查图片显示
- [ ] 检查响应式布局

### 阶段4：上传部署（2分钟）
- [ ] git add .
- [ ] git commit -m "描述修改内容"
- [ ] git push origin main
- [ ] 告知用户清除缓存测试

## 常见错误及解决方案

| 错误 | 原因 | 解决方案 |
|------|------|----------|
| 图片404 | 文件名不匹配 | 检查images文件夹名称和HTML中的路径 |
| 样式不生效 | CSS缓存 | 告知用户Ctrl+Shift+R强制刷新 |
| 中文乱码 | 文件编码问题 | 确保使用UTF-8 without BOM编码 |
| Git冲突 | 多人编辑 | 先git pull再修改 |
| 图片太大 | 未压缩 | 使用TinyPNG压缩到500KB以下 |

## 文件结构速查

```
yier-studio/
├── index.html              # 首页（轮播图）
├── about.html              # 关于页面
├── projects.html           # 项目列表
├── project-detail.html     # 项目详情（修改这里添加项目）
├── contact.html            # 联系页面
├── css/
│   └── yier-style.css      # 主样式（修改这里调整样式）
├── js/
│   └── main.js             # 主脚本
└── images/
    └── [项目名]/           # 每个项目一个文件夹
        ├── cover.jpg       # 封面图
        └── 1.jpg - 7.jpg   # 详情图
```

## 常用命令

```bash

cd E:/portfolio/yier-studio

git add .

git log --oneline
```

## 图片规范

### 格式要求
- 照片：JPG，质量75%
- 阴影/透明：PNG
- 图标：PNG

### 尺寸建议
- 封面图：1920×1080 像素
- 详情图：1920×宽 像素
- 单张不超过 2MB

### 压缩工具
- 在线：https://tinypng.com
- 批量：https://squoosh.app
- 本地：Photoshop导出
