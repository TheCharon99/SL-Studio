# 客服 Agent 测试指南

## 一、测试前准备

### 1. 确认环境
```bash
# 检查 dsh 是否运行
curl -s http://127.0.0.1:3080/ | head -20

# 检查插件是否加载
ls -la ~/.dsh/profiles/web/cordis.patch.yml
```

### 2. 启动 dsh（如果未运行）
```bash
npx @deepseek-ai/dsh web
```

访问 http://127.0.0.1:3080

## 二、在 Web UI 中测试

### 步骤 1：创建新会话
1. 打开 http://127.0.0.1:3080
2. 点击"新建会话"
3. 选择模型：`agnes-2.5-pro`（客服建议用 pro 版本）

### 步骤 2：加载 FAQ 知识库
在会话中输入：
```
请加载 FAQ 知识库，路径是：E:/portfolio/dsh-plugins/customer-service-agent/FAQ示例.json
```

### 步骤 3：测试常见问题

#### 测试 1：订单查询
**用户输入**：
```
我的订单什么时候发货？
```

**预期结果**：
- Agent 调用 faq_retriever 工具
- 返回："您的订单将在付款后 1-2 个工作日内发货..."
- 显示相似度得分

#### 测试 2：退款咨询
**用户输入**：
```
我要申请退款，怎么操作？
```

**预期结果**：
- Agent 返回退款流程
- 可能需要转人工（如果用户情绪激动）

#### 测试 3：投诉场景
**用户输入**：
```
你们的服务太差了，我要投诉！
```

**预期结果**：
- Agent 识别为投诉意图
- 自动转接人工客服
- 显示优先级：urgent 或 high

#### 测试 4：多轮对话
**用户输入**：
```
用户：我的快递到哪了？
Agent：（查询物流）
用户：已经三天了还没到
Agent：（理解用户不满，可能转人工）
```

## 三、测试工具调用

### 测试 faq_retriever
```bash
curl -X POST http://127.0.0.1:3080/api/tools/faq_retriever \
  -H "Content-Type: application/json" \
  -d '{
    "question": "我的订单什么时候发货？",
    "top_k": 3
  }'
```

**预期响应**：
```json
{
  "found": true,
  "answers": [
    {
      "question": "我的订单什么时候发货？",
      "answer": "您的订单将在付款后 1-2 个工作日内发货...",
      "similarity": 1.0,
      "category": "订单查询"
    }
  ]
}
```

### 测试 conversation_manager
```bash
curl -X POST http://127.0.0.1:3080/api/tools/conversation_manager \
  -H "Content-Type: application/json" \
  -d '{
    "action": "create",
    "user_id": "test_user_001"
  }'
```

### 测试 escalation_manager

```bash
cat ~/.dsh/profiles/web/cordis.patch.yml

ls -la E:/portfolio/dsh-plugins/customer-service-agent/index.js
```

### 问题 2：FAQ 未加载
```bash
# 检查 FAQ 文件
cat E:/portfolio/dsh-plugins/customer-service-agent/FAQ示例.json | jq .

node -e "
const { loadFAQ } = require('./tools/faq-retriever.js');
loadFAQ('E:/portfolio/dsh-plugins/customer-service-agent/FAQ示例.json');
"
```

### 问题 3：模型响应慢
```bash

curl https://apihub.agnes-ai.com/v1/models \
  -H "Authorization: Bearer $AGNES_API_KEY"
```
