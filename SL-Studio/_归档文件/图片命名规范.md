# 懿贰设计网站 - 图片命名规范

## 图片命名规则

### 项目图片
```
格式：项目名称_序号.jpg
示例：懿贰设计自宅_1.jpg
      懿贰设计自宅_2.jpg
      远洋鸿郡_1.jpg
      远洋鸿郡_2.jpg
```

### 轮播图
```
格式：banner序号.jpg
示例：banner1.jpg
      banner2.jpg
      banner3.jpg
      banner4.jpg
      banner5.jpg
      banner6.jpg
```

### 占位图
```
格式：detail_序号.jpg
示例：detail_1.jpg
      detail_2.jpg
      detail_3.jpg
      detail_4.jpg
      detail_5.jpg
      detail_6.jpg
```

### Logo和图标
```
logo.png      # 网站Logo
wx.png        # 微信图标
wx2.png       # 微信二维码
s_l.png       # 上一页按钮
s_r.png       # 下一页按钮
s_x.png       # 项目列表按钮
```

---

## 图片规格建议

### 主图（项目详情页）
- 尺寸：960×640px 或更大
- 格式：JPG（质量80-90%）
- 文件大小：< 500KB

### 缩略图（项目列表）
- 尺寸：210×150px
- 格式：JPG
- 文件大小：< 50KB

### 轮播图（首页）
- 尺寸：1920×1080px 或更大
- 格式：JPG
- 文件大小：< 300KB

---

## 注意事项

1. **文件名不要有空格**（使用下划线 `_` 代替）
2. **使用英文或拼音**更稳定（避免中文乱码）
3. **序号从1开始**，连续递增
4. **主图序号为_1**，后续图片依次递增
5. **图片格式统一**为 JPG 或 PNG

## 示例：添加新项目"清风别墅"

### 1. 上传图片
```
images/
├── 清风别墅_1.jpg    ← 主图（第一个显示）
├── 清风别墅_2.jpg
├── 清风别墅_3.jpg
└── 清风别墅_4.jpg
```

### 2. 更新 projects.html
```html
<li data-tag="私人豪宅,全部">
    <div class="projects-thumb">
        <div class="recent-project-details">
            <a href="project-detail.html?project=清风别墅">
```
