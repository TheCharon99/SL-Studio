## 图片懒加载

所有 `<img>` 标签添加 `loading="lazy"`：
```html
<img src="..." alt="..." loading="lazy">
```

批量添加脚本：
```bash
node -e "const fs=require('fs'); const html=fs.readFileSync('file.html','utf8'); const modified=html.replace(/<img\s+src=/g, '<img loading=\"lazy\" src='); fs.writeFileSync('file.html', modified);"
```

## 常见错误检查清单

修改后验证：
```bash

grep -rn "yier\|YiER\|懿贰" *.html js/ css/

# 检查meta标签
grep -n "meta name=\"description\"" *.html

# 检查懒加载
grep -c "loading=\"lazy\"" *.html

# 检查设计师字段
grep -n "designer" project-detail.html | head -5

# 检查导航链接是否正确
grep -n "href=\".*\.html\"" index.html
```
