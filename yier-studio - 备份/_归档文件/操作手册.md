## 二、如何添加新项目

### 2.1 在项目精选列表页添加项目

编辑文件：`projects.html`

**步骤：**
1. 找到对应分类区域（私人豪宅/私人公寓/办公室/商业空间）
2. 复制一个现有的 `<li>` 块
3. 修改以下属性：

```html
<li data-tag="分类名称,全部">
    <div class="projects-thumb">
        <div class="recent-project-details">
            <a href="project-detail.html?project=项目名称">
                <img width="210" height="150" alt="项目名称" src="images/图片文件名.jpg" />
                <div class="thumb-cover" style="top:-137px;"><div class="thumb-more"></div></div>
            </a>
            <h5>项目名称</h5>
        </div>
    </div>
</li>
```

**注意事项：**
- `data-tag` 必须是以下之一：`私人豪宅`、`私人公寓`、`办公室`、`商业空间`
- `project=` 后面的参数必须与 `project-detail.html` 中的键名完全一致
- `src` 是图片路径，`alt` 是图片描述

---

### 2.2 在项目详情页添加项目数据

编辑文件：`project-detail.html`

**步骤1：** 在 `projects` 对象中添加新项目数据：

```javascript
var projects = {
    // ... 现有项目 ...
    
    '新项目名': {
        name: '新项目名',           // 项目名称（显示用）
        designer: '懿贰设计',       // 设计单位
        location: '上海',           // 项目地址
        desc: '设计说明文字...',    // 设计说明
        images: [                   // 图片数组（按顺序显示）
            '新项目名_1.jpg',
            '新项目名_2.jpg',
            '新项目名_3.jpg'
        ]
    }
};
```

**步骤2：** 在 `projectOrder` 数组中添加项目顺序：

```javascript
var projectOrder = [
    // ... 现有项目顺序 ...
    '新项目名'  // 添加到对应分类位置
];
```

**注意事项：**
- 项目名称必须与 `projects.html` 中的 `project=` 参数完全一致
- 图片文件名必须与 `images/` 目录中的实际文件名一致

---

### 2.3 添加项目图片

**图片命名规范：**
```
项目名称_序号.jpg
```

**示例：**
```
images/
├── 新项目名_1.jpg    ← 主图（第一个显示的图）
├── 新项目名_2.jpg
├── 新项目名_3.jpg
└── 新项目名_4.jpg
```

**推荐规格：**
- 主图：宽度至少 960px，高度 640px 左右
- 格式：JPG 或 PNG
- 压缩：文件大小建议 200KB 以内

## 三、如何修改现有内容

### 3.1 修改首页内容

编辑文件：`index.html`

- 导航菜单：修改 `<nav class="nav__links">` 中的链接
- Hero区域：修改 `.hero__title` 和 `.hero__subtitle`
- 关于区域：修改 `.about__text` 中的文字
- 服务卡片：修改 `.service-card` 中的标题和描述
- 项目展示：修改 `.project` 中的图片和标题

### 3.2 修改关于页内容

编辑文件：`about.html`

- 左侧导航：修改 `<ul>` 中的链接
- 正文内容：修改 `<div id="middle">` 中的文字

### 3.3 修改联系页内容

编辑文件：`contact.html`

- 联系表单：修改 `<form>` 中的字段
- 右侧信息：修改 `<div id="add">` 中的地址、电话、邮箱
- 地图：修改 `<iframe>` 的 src 属性（如需更换地图位置）

## 四、图片管理

### 4.1 图片存放规则

所有图片统一存放在 `images/` 目录：

```
images/
├── logo.png              # Logo（必需）
├── wx.png                # 微信图标（必需）
├── wx2.png               # 微信二维码（必需）
├── banner1.jpg ~ banner6.jpg  # 首页轮播图（可选）
├── detail_1.jpg ~ detail_6.jpg # 项目占位图（可选）
│
├── 项目名_1.jpg          # 项目图片（按项目分类）
├── 项目名_2.jpg
└── ...
```

### 4.2 图片优化建议

- 使用工具压缩图片（如 TinyPNG）
- 保持统一尺寸和比例
- 使用描述性的文件名（中文或英文）

## 五、常见问题

### Q1: 图片不显示怎么办？
**检查：**
1. 图片文件是否存在于 `images/` 目录
2. 文件名拼写是否正确（区分大小写）
3. 代码中的 `src` 路径是否正确

### Q2: 筛选功能不工作？
**检查：**
1. `data-tag` 属性值是否正确（必须是：私人豪宅、私人公寓、办公室、商业空间）
2. jQuery 是否正确加载
3. 浏览器控制台是否有报错

### Q3: 项目详情页显示404？
**检查：**
1. `project-detail.html` 文件是否存在
2. URL参数 `?project=` 后面的名称是否与 `projects` 对象中的键名完全一致

### Q4: 图片显示变形？
**检查：**
1. 图片尺寸是否与 CSS 中定义的不匹配
2. 是否在 CSS 中设置了 `object-fit: cover`
