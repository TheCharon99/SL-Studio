# YiER Studio 快速操作指南

## 常用命令（在项目文件夹运行）

### 查看状态
```bash
python batch_tools.py status
```

### 创建新项目
```bash
python batch_tools.py add "项目名-风格"
# 例：python batch_tools.py add "紫金府-现代简约"
```

### 提交更改
```bash
python batch_tools.py commit "添加新项目：紫金府"
```

### 检查大图
```bash
python batch_tools.py check-images
```

### 批量压缩
```bash
python batch_tools.py compress
```

### 打开网站
```bash
python batch_tools.py open
```

### 打开CSS文件
```bash
python batch_tools.py open-css
```

## 添加新项目完整流程

```bash
# 1. 创建文件夹
python batch_tools.py add "紫金府-现代简约"

# 2. 放入图片（cover.jpg + 1-7.jpg）

# 3. 编辑 project-detail.html 添加数据：
#    id: "紫金府-现代简约"
#    cover: "images/紫金府-现代简约.jpg/cover.jpg"
#    ...

# 4. 编辑 projects.html 添加链接

# 5. 提交推送
python batch_tools.py commit "添加新项目：紫金府"
```

## 修改项目信息

```bash
# 1. 打开项目详情页
python batch_tools.py open-detail

# 2. 搜索项目ID（如：金山豪庭-中古奶油）

# 3. 修改字段：
#    title: "新标题"
#    area: "新面积"
#    description: "新描述"

python batch_tools.py commit "修改项目信息：金山豪庭"
```

## 注意事项

### 图片规范
- 格式：JPG（照片）、PNG（阴影/透明）
- 尺寸：封面1920×1080，详情图1920×宽
- 大小：单张不超过2MB
- 压缩：使用 https://tinypng.com

### 文件命名
- 项目文件夹：`项目名-风格.jpg`（如：紫金府-现代简约.jpg）
- 封面图：`cover.jpg`
- 详情图：`1.jpg` 到 `7.jpg`

### 编码要求
- 所有HTML/CSS/JS文件：UTF-8 without BOM
- 换行符：LF（Unix风格）

## 故障排查

### 网站不显示新内容
```bash
# 清除浏览器缓存
# 按 Ctrl+Shift+Delete
# 或硬刷新 Ctrl+Shift+R
```

### 图片不显示
```bash
# 检查图片路径是否正确
# 检查图片文件名是否匹配
python batch_tools.py check-images
```

### Git提交失败
```bash
# 检查是否有未提交的修改
python batch_tools.py status

# 删除锁文件（如果有）
del .git\index.lock
```
