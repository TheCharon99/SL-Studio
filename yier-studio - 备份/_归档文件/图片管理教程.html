一、图片文件夹结构

📁 images/
├── 项目-banner1.jpg ~ 项目-banner6.jpg   # 首页轮播图（6张）
├── 项目名1/
│   ├── cover.jpg                        # 项目封面图（首页/列表显示）
│   ├── 1.jpg ~ 7.jpg                    # 项目详情图（可选，1-7张）
├── 项目名2/
│   ├── cover.jpg
│   └── 1.jpg ~ 7.jpg
└── ...
📌 命名规则：
  • 文件夹名 = 网页显示的项目名（可用中文、空格、连字符）
  • 封面图固定命名为 cover.jpg
  • 详情图固定命名为 1.jpg, 2.jpg, 3.jpg... 从1开始连续编号
  • 首页轮播图：项目-banner1.jpg ~ 项目-banner6.jpg

二、修改项目图片

1修改项目封面图

✅ 步骤：
  1. 将新图片复制到对应项目文件夹
  2. 命名为 cover.jpg（覆盖原图）
  3. 刷新浏览器即可看到更新

示例：修改"观唐府"封面
复制新图片 → images/观唐府-意式风格/cover.jpg

2修改项目详情图

✅ 步骤：
  1. 将新图片复制到对应项目文件夹
  2. 按顺序命名为 1.jpg, 2.jpg, 3.jpg...
  3. 删除不需要的图（直接删除文件即可）
  4. 刷新浏览器

注意：编号必须从1开始连续递增，删除中间的图需重新命名

3修改首页轮播图

✅ 步骤：
  1. 将新图片复制到 images/ 文件夹
  2. 命名为 项目-banner1.jpg ~ 项目-banner6.jpg
  3. 刷新浏览器

注意：必须保持6张，序号不能跳过，删除后需重命名后续图片填补空缺

三、新增项目

1创建图片文件夹

在 images/ 下新建文件夹，命名规则：
  • 中文名，无特殊符号
  • 例如：images/新项目名称/

2放置图片

📁 新项目名称/
├── cover.jpg      ← 封面图（必须）
├── 1.jpg          ← 详情图1（可选）
├── 2.jpg          ← 详情图2（可选）
├── 3.jpg          ← 详情图3（可选）
└── ...

3更新 HTML 文件

① 更新 project-detail.html（第82-155行）

在 var projects = { 中添加新条目： 
'新项目名称': {
    name: '新项目名称',
    designer: '懿贰设计',
    location: '上海·金山',
    desc: '项目描述文字',
    images: [
        'images/新项目名称/cover.jpg',
        'images/新项目名称/1.jpg',
        'images/新项目名称/2.jpg'
    ]
},
在 var projectOrder = [ 中添加项目名： 
var projectOrder = [
    '观唐府 · 意式风格','金山豪庭 · 中古奶油',
    // ... 其他项目 ...
    '新项目名称'   // ← 添加到这里
];

② 更新 projects.html（项目列表页）

在 <ul class="projects three-columns" id="filter_gallery"> 中添加： 
<li data-category="私人豪宅">
    <div class="projects-thumb">
        <div class="recent-project-details">
            <a href="project-detail.html?project=新项目名称">
                <img width="210" height="150" 
                     alt="新项目名称" 
                     src="images/新项目名称/cover.jpg" />
                <div class="thumb-cover" style="top:-137px;">
                    <div class="thumb-more"></div>
                </div>
            </a>
            <h5>新项目名称</h5>
        </div>
    </div>
</li>

注意：

  • data-category 分类可选：私人豪宅、私人公寓、办公室、商业空间
  • href 中的 project 参数必须与 project-detail.html 中的 key 完全一致

③ 更新 index.html（首页，可选）

在"最新项目"区域添加： 
<li style="text-align:center">
    <div class="projects-thumb">
        <div class="recent-project-details">
            <a href="project-detail.html?project=新项目名称">
                <img width="210" height="150" 
                     alt="新项目名称" 
                     src="images/新项目名称/cover.jpg" />
                <div class="thumb-cover" style="top:-137px;">
                    <div class="thumb-more"></div>
                </div>
            </a>
            <h5>新项目名称</h5>
        </div>
    </div>
</li>

四、删除项目

1删除图片文件夹

删除 images/新项目名称/ 整个文件夹

2更新 project-detail.html

  1. 删除对应的项目条目（从 var projects 中）
  2. 从 projectOrder 数组中移除对应的项目名

3更新 projects.html

删除对应的 <li>...</li> 块

4更新 index.html

删除对应的 <li>...</li> 块

五、修改首页轮播图

1替换轮播图

✅ 步骤：
  1. 将新图片复制到 images/ 文件夹
  2. 命名为 项目-banner1.jpg ~ 项目-banner6.jpg
  3. 更新 index.html 中的 alt 描述文字

2轮播图代码位置

index.html 第46-55行： 
<div class="home-slider" id="slider">
    <img class="slide active" src="images/项目-banner1.jpg" alt="图片描述1" />
    <img class="slide" src="images/项目-banner2.jpg" alt="图片描述2" />
    <img class="slide" src="images/项目-banner3.jpg" alt="图片描述3" />
    <img class="slide" src="images/项目-banner4.jpg" alt="图片描述4" />
    <img class="slide" src="images/项目-banner5.jpg" alt="图片描述5" />
    <img class="slide" src="images/项目-banner6.jpg" alt="图片描述6" />
    <a href="#" class="slider-nav prev" aria-label="上一张">‹</a>
    <a href="#" class="slider-nav next" aria-label="下一张">›</a>
</div>

六、常用操作速查表

操作 修改文件 优先级
修改封面图 images/项目名/cover.jpg 必须
修改详情图 images/项目名/1.jpg ~ N.jpg 必须
新增项目 新建文件夹 + 3个HTML 必须
删除项目 删除文件夹 + 3个HTML 必须
修改轮播图 images/项目-banner*.jpg + index.html 可选

七、注意事项

⚠️ 重要提醒：
  • 文件夹名必须与 HTML 中的项目 key 完全一致（区分大小写）
  • 图片编号必须从1开始连续，不能跳号
  • HTML 中的 ?project=项目名 必须与 project-detail.html 中的 key 一致
  • 删除图片后记得更新 HTML，否则会显示空白
  • 轮播图必须是6张，序号不能跳过
💡 提示：修改完成后，建议在不同设备上测试显示效果，确保图片路径正确。
