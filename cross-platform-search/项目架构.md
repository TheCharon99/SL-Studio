```
              Notion 搜索           本地文件搜索          Gmail 搜索
                    ↓                    ↓                    ↓
                    └────────────────────┼────────────────────┘
                                         ↓
                                    结果融合
                                         ↓
                                    AI 总结
                                         ↓
                                    返回前端
                                         ↓
                                    展示结果
```

```json
    "version": "1.0.0"

  "search": {
```

## 快捷键设计

| 快捷键 | 功能 |
|--------|------|
| `Ctrl/Cmd + Space` | 打开搜索框 |
| `Enter` | 执行搜索 |
| `↑/↓` | 选择结果 |
| `Enter` | 打开结果 |
| `Esc` | 关闭搜索框 |
| `Ctrl/Cmd + K` | 清空搜索 |
| `Ctrl/Cmd + H` | 打开历史记录 |
| `Ctrl/Cmd + ,` | 打开设置 |
