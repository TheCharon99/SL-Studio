### 方式一：使用 sl-studio.cc.cd（推荐）
1. 等待 Cloudflare zone 完成初始化（约 5-10 分钟）
2. 登录 https://dash.cloudflare.com/
3. 进入 DNS → Records
4. 找到 sl-studio.cc.cd 的 CNAME 记录
5. 修改 Content 为: `shenling-studio-a23.pages.dev`
6. 确保 Proxy status 为 Proxied (橙色云)

### 方式二：使用 sl-studio.bbroot.com
1. 登录 https://dash.cloudflare.com/
2. 进入 DNS → Records
3. 添加新记录:
   - Type: CNAME
   - Name: sl-studio
   - Content: shenling-studio-a23.pages.dev
   - Proxy status: Proxied (橙色云)

### 方式三：在 Cloudflare Pages 中绑定域名（自动添加 DNS）
1. 登录 https://dash.cloudflare.com/
2. 进入 Workers & Pages
3. 点击 shenling-studio 项目
4. 点击 Custom domains
5. 点击 Set up a custom domain
6. 输入 sl-studio.cc.cd 或 sl-studio.bbroot.com
7. 确认 DNS 记录（系统会自动添加或提示你添加）
