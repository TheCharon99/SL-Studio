# Video Editing Workflow for Motion Comics

## CapCut (剪映专业版)

### Import & Setup
1. **New Project** → Import video
2. **Aspect Ratio**: 16:9 (1920×1080)
3. **Frame Rate**: 24fps or 30fps

### Audio Layering
```
Timeline Structure:
├── Video Track 1 (Main footage)
├── Audio Track 1 (Voice/Narration)
├── Audio Track 2 (Sound Effects)
└── Audio Track 3 (Background Music)
```

### Voice Sync Steps
1. Import voice file
2. Drag to Audio Track 1
3. Align with video timeline
4. Use waveform visualization
5. Add silence gaps between lines

### Sound Effect Placement
- Add effects on separate track
- Align with visual actions
- Use fade in/out (0.2s)
- Adjust volume per scene

### Music Integration
- Drag to Audio Track 3
- Set to 10-15% volume
- Use crossfade transitions
- Match music beats to cuts

### Subtitle Styling
**Wuxia Style:**
- Font: 楷体 or 仿宋
- Color: White with black stroke
- Position: Bottom center

### Export Settings
```
Resolution: 1920×1080 (1080p)
Frame Rate: 30fps
Codec: H.264
Bitrate: 10 Mbps
Audio: AAC, 128kbps
Format: MP4
```

## Common Issues & Solutions

| Issue | Solution |
|-------|----------|
| Voice too fast | Slow down to 80-90% speed |
| Audio out of sync | Use waveform alignment |
| Music too loud | Reduce to 10-15% |
| Echo on voice | Add noise gate |
