## 我犯过的错误

### 1. 部署方案错误
- **错误**: 最初使用Vercel部署
- **问题**: Vercel免费版100MB限制，图片总大小129MB超限
- **后果**: CSS/JS/图片大量404错误
- **正确做法**: 应直接选择GitHub Pages，更适合静态网站

### 2. 中文文件名问题
- **错误**: 未提前处理中文文件名编码
- **问题**: Git推送时可能出现编码问题
- **后果**: 需要反复修复文件编码
- **正确做法**: 早期就统一使用UTF-8 without BOM编码

### 3. 图片格式错误
- **错误**: 使用JPEG格式存储阴影图片
- **问题**: JPEG压缩导致阴影颜色变深、失去透明度
- **后果**: 视觉效果不佳，需要多次替换
- **正确做法**: 阴影和透明元素应使用PNG格式

### 4. 微信二维码样式问题
- **错误**: 首次尝试用CSS `width: auto`修复变形
- **问题**: 导致二维码无法弹出
- **后果**: 需要回滚修改，再次调试
- **正确做法**: 保持原始CSS定位，只调整图片显示

### 5. 轮播图顺序调整
- **错误**: 修改HTML顺序后，远程CDN缓存旧版本
- **问题**: 用户看到旧内容，以为修改失败
- **后果**: 需要等待CDN更新或强制刷新
- **正确做法**: 修改后立即告知用户清除缓存测试

### 6. 图标缺失
- **错误**: 添加新图标时未完整复制所有文件
- **问题**: 图标显示为乱码或空白
- **后果**: 需要多次尝试才能正确显示
- **正确做法**: 先确认所有图标文件已复制，再修改HTML

### 7. Git锁定问题
- **错误**: 多次执行git命令导致index.lock文件残留
- **问题**: 无法执行git操作
- **后果**: 需要手动删除锁文件
- **正确做法**: 先检查git状态，避免并发操作

## 技术要点总结

### 网站结构
```
yier-studio/
├── index.html          # 首页（轮播图）
├── about.html          # 关于页面
├── projects.html       # 项目列表
├── project-detail.html # 项目详情（JS数据）
├── contact.html        # 联系页面
├── career.html         # 事业机会
├── css/
│   └── yier-style.css  # 主样式
├── js/
│   └── main.js         # 主脚本
└── images/
    └── [项目名]/       # 每个项目文件夹
```

### 关键配置
- 编码: UTF-8 without BOM
- 换行符: LF（Unix风格）
- 图片格式: JPG（压缩质量75%）
- 阴影图片: PNG（保留透明度）

### 部署流程
1. 修改本地文件
2. `git add .`
3. `git commit -m "说明"`
4. `git push origin main`
5. 等待1-3分钟CDN更新
6. `Ctrl+Shift+R` 强制刷新浏览器

## 经验教训

### 对开发者
1. **部署方案要选对**: 静态网站优先GitHub Pages
2. **中文路径要提前处理**: 统一编码和文件名
3. **图片格式要规范**: 透明用PNG，照片用JPG
4. **CDN缓存要提醒**: 修改后告知用户清缓存
5. **Git操作要谨慎**: 避免并发和锁文件

### 对用户
1. **先确认方案再动手**: 避免方向性错误
2. **备份重要文件**: 防止意外丢失
3. **理解基本流程**: 知道如何上传更新
4. **遇到问题先检查**: 缓存、编码、路径
