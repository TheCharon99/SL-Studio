# 客服 Agent 部署指南

## 一、插件开发完成

已创建完整的客服 Agent 插件，包含：

### 1. 核心工具
- `faq-retriever.ts` - FAQ 智能检索
- `conversation.ts` - 对话历史管理
- `escalation.ts` - 人工转接管理

### 2. 配置
- `customer-service.ts` - Agent 预设配置
- `FAQ示例.json` - 示例知识库

## 二、集成到 dsh

### 方法一：本地开发测试

```bash
# 1. 进入插件目录
cd E:\portfolio\dsh-plugins\customer-service-agent

# 2. 安装依赖
npm install

# 3. 编译插件
npm run build

# 4. 配置到 dsh
# 编辑 ~/.dsh/profiles/web/cordis.patch.yml
```

### 方法二：生产部署

```bash
# 1. 发布到 npm（可选）
npm publish

# 2. 在其他机器安装
npm install customer-service-agent

# 3. 配置使用
```

## 三、测试步骤

### 1. 启动 dsh
```bash
npx dsh web
```

### 2. 配置插件
编辑 `~/.dsh/profiles/web/cordis.patch.yml`:

```yaml
plugins:
  - path: E:/portfolio/dsh-plugins/customer-service-agent
    name: customer-service-agent
```

### 3. 加载 FAQ
在插件代码中调用：
```typescript
import { loadFAQ } from './tools/faq-retriever'
await loadFAQ('E:/portfolio/dsh-plugins/customer-service-agent/FAQ示例.json')
```

### 4. 选择客服预设
在 Web UI 中选择 "customer-service" preset

### 5. 测试对话
- 测试简单问题："我的订单什么时候发货？"
- 测试复杂问题："我要退款，你们太坑了！"
- 测试转人工："我要找你们经理！"

## 四、性能优化建议

### 1. FAQ 检索优化
- 使用 embedding 替代关键词匹配
- 接入向量数据库（如 Milvus、Chroma）
- 缓存高频问题

### 2. 对话管理优化
- 使用 Redis 存储对话历史
- 实现对话压缩（长对话自动总结）
- 支持多会话并行

### 3. 转接优化
- 接入真实客服系统（如 Zendesk、网易七鱼）
- 实现客服排队机制
- 添加聊天记录导出功能
