# 图片资源目录

请将以下图片放置在此目录：

- `logo.png` - 应用Logo（建议尺寸：100x100）
- `home.png` / `home-active.png` - 首页Tab图标
- `create.png` / `create-active.png` - 发布Tab图标
- `profile.png` / `profile-active.png` - 我的Tab图标
- `default-avatar.png` - 默认头像
- `empty.png` - 空状态图片
- `empty-match.png` - 匹配空状态图片

## 临时方案

目前项目使用占位符，请先：
1. 在微信开发者工具中创建一个临时图片资源
2. 或使用emoji代替（已部分实现）
