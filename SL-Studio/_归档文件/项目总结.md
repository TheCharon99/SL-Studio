## 🎨 设计特点

### 布局
- **宽度**：960px 固定（与 wdesign.hk 一致）
- **导航**：水平菜单，当前页底部黑线高亮
- **项目卡片**：210×150，3列网格
- **间距**：模块化间距（8px 基础单位）

### 配色
```
背景：    #ededed（浅灰）
文字：    #333333（深灰）、#999999（浅灰）
强调：    #000000（纯黑）
分隔线：  #ededed
```

### 字体
```
字体族：  "Microsoft Yahei", "微软雅黑", sans-serif
基础字号：12px
标题：    14-18px
行高：    1.5-2.0
```

---

## 📱 响应式断点

| 断点 | 布局 |
|------|------|
| ≥960px | 960px 固定，3列网格 |
| 768-960px | 自适应，2列网格 |
| ≤768px | 单列，select 下拉导航 |
| ≤640px | 优化间距 |
| ≤480px | 进一步优化 |

## 🔧 技术栈
