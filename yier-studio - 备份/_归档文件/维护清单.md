# YiER-Studio 懿贰设计 - 网站维护清单

## 每日检查
- [ ] 检查网站是否正常访问
- [ ] 检查所有链接是否有效
- [ ] 检查图片是否全部显示

## 添加新项目
- [ ] 拍摄/准备项目图片（至少1张，建议3-5张）
- [ ] 按规范命名图片文件
- [ ] 上传图片到 `images/` 目录
- [ ] 在 `projects.html` 添加项目卡片
- [ ] 在 `project-detail.html` 添加项目数据
- [ ] 更新 `projectOrder` 数组
- [ ] 测试筛选功能和详情页

## 修改项目信息
- [ ] 确认要修改的项目名称
- [ ] 更新 `project-detail.html` 中的项目数据
- [ ] 如需更换图片，按规范命名并上传
- [ ] 更新 `images` 数组
- [ ] 测试显示效果

## 更换项目图片
- [ ] 备份原图片（可选）
- [ ] 删除旧图片
- [ ] 上传新图片（按命名规范）
- [ ] 更新 `project-detail.html` 中的 `images` 数组
- [ ] 刷新浏览器测试

## 添加首页轮播图
- [ ] 准备6张轮播图（1920×1080px）
- [ ] 命名为 `banner1.jpg` ~ `banner6.jpg`
- [ ] 上传到 `images/` 目录
- [ ] 测试首页显示

## 更新联系方式

## 常见问题速查

| 问题 | 解决方案 |
|------|----------|
| 图片不显示 | 检查文件名和路径是否正确 |
| 筛选不工作 | 检查 data-tag 值是否正确 |
| 详情页404 | 检查 project 参数是否与数据键一致 |
| 图片变形 | 检查 CSS 中的 object-fit 设置 |
