# 项目自查报告

## 已发现的问题

### 1. 导航栏不统一
- 首页有5个菜单项：首页、关于我们、项目精选、事业机会、联系我们
- about.html 只有4个：关于我们、项目精选、事业机会、联系我们（缺少首页）
- career.html 只有4个：关于我们、项目精选、事业机会、联系我们（缺少首页）
- contact.html 只有4个：关于我们、项目精选、事业机会、联系我们（缺少首页）
- projects.html 有重复的 me2 div，导航结构混乱

### 2. 项目分类页面问题
- 存在两个 id="me2" 的 div（第45-53行和第56-64行）
- 第一个 me2 包含的是错误菜单项（没有首页）
- 移动端 select 导航重复

### 3. 项目详情页面问题
- 当前激活项错误显示为「项目精选」而非实际选中状态
- 使用了全局未定义的 `currentLang` 变量（应该在 lang-switch.js 中定义）
- 图片切换器 `shownext` 函数使用全局变量 `_show`，多个项目时会冲突
- 翻译数据 `translations` 定义在页面内，但应该复用 lang-switch.js

### 4. 关于我们页面问题
- 缺少首页菜单项
- 内容严重缺失，只有项目列表文字
- 缺少完整的about内容结构

### 5. 事业机会页面问题
- 缺少首页菜单项
- 内容过于简单，只有两行文字

### 6. 联系我们页面问题
- 表单完全为空，没有任何输入框
- `checkForm()` 函数是空函数

### 7. 首页问题
- 使用了不存在的 placeholder 图片 (placeholder_1.jpg, placeholder_2.jpg, placeholder_3.jpg)
- 应该使用真实项目图片

### 8. CSS/JS问题
- jQuery 版本混乱 (jquery-1.4.2.min.js 实际内容是 1.8.3)
- style.css 包含大量 WordPress 遗留代码（~2700行，大部分未使用）
- script.js 包含大量未使用的代码
- nivo-slider.css 和 imggray.css 加载但未使用

### 9. 图片问题
- 大部分项目使用了 banner*.jpg 作为缩略图，而非真实项目图片
- 只有「懿贰设计自宅」使用了真实图片

## 修复优先级
P0: 导航统一、项目详情bug、表单功能
P1: 图片修复、页面内容完善
P2: CSS精简、代码清理
