# 🎯 跨平台搜索 - 完整产品方案

## 一、产品定位

### 一句话描述
**"你的私人 AI 搜索助手，一个命令找到所有地方的信息"**

### 核心价值
1. **隐私优先**：所有数据本地处理，永不上传
2. **智能理解**：AI 语义搜索，不只是关键词匹配
3. **跨平台整合**：Notion、邮件、本地文件统一搜索
4. **一次买断**：¥299 永久使用，无订阅

### 目标用户
- **核心用户**：Notion 重度用户（设计师、程序员、研究者）
- **扩展用户**：信息密集工作者（每天查 10+ 次资料）
- **付费用户**：愿意为效率付费的知识工作者

## 三、技术架构

### 整体架构
```
┌─────────────────────────────────────────┐
│           用户界面 (Tauri)               │
│  ┌─────────┐ ┌─────────┐ ┌─────────┐  │
│  │ 搜索框  │ │ 历史    │ │ 设置    │  │
│  └────┬────┘ └────┬────┘ └────┬────┘  │
└───────┼────────────┼────────────┼──────┘
        │            │            │
┌───────┴────────────┴────────────┴──────┐
│           核心引擎 (Python)             │
│  ┌─────────┐ ┌─────────┐ ┌─────────┐  │
│  │ 搜索    │ │ AI      │ │ 索引    │  │
│  │ 路由    │ │ 理解    │ │ 管理    │  │
│  └────┬────┘ └────┬────┘ └────┬────┘  │
└───────┼────────────┼────────────┼──────┘
        │            │            │
┌───────┴────────────┴────────────┴──────┐
│           数据源适配层                  │
│  ┌─────┐ ┌─────┐ ┌─────┐ ┌─────┐    │
│  │Notion│ │Gmail│ │本地 │ │Obsidian│  │
│  └───┬──┘ └───┬──┘ └───┬──┘ └───┬──┘  │
└──────┼────────┼────────┼────────┼─────┘
       │        │        │        │
  ┌────┴────┐ ┌┴────┐ ┌──┴──┐ ┌──┴──┐
  │Notion API│ │OAuth│ │文件系统│ │Markdown│
  └─────────┘ └─────┘ └─────┘ └─────┘
```

### 技术栈
```
前端：Tauri 2.0 + React + Tailwind CSS
后端：Python 3.11 + FastAPI
向量库：ChromaDB（本地）
嵌入模型：text-embedding-3-small（OpenAI）或 BGE-M3（本地）
数据库：SQLite（元数据）+ ChromaDB（向量）
搜索：混合搜索（BM25 + 向量相似度）
打包：Tauri（原生应用）
```

## 四、商业模式

### 定价策略
| 版本 | 价格 | 功能 | 目标 |
|------|------|------|------|
| **免费版** | ¥0 | 本地文件搜索，50次/天 | 获客 |
| **个人版** | ¥299 | 所有功能，永久授权 | 主力产品 |
| **家庭版** | ¥499 | 5个设备，永久授权 | 家庭用户 |
| **开发者版** | ¥999 | API 访问，插件开发 | 生态建设 |

### 为什么只做永久版？
1. **用户信任**：一次付费，终身使用
2. **口碑传播**：无订阅压力，推荐意愿强
3. **现金流**： upfront 收入，有利于开发
4. **差异化**：竞品多是订阅制，我们不同

### 获客策略
1. **Product Hunt** 发布
2. **即刻/小红书** 种草
3. **技术博客** 教程
4. **推荐奖励**：推荐 1 人得 ¥50 现金

## 六、竞争优势

### 技术壁垒
1. **本地优先**：所有数据本地处理，隐私无忧
2. **混合搜索**：关键词 + 语义 + 向量，准确率高
3. **插件系统**：可扩展数据源，生态丰富
4. **AI 增强**：智能总结、相关推荐

### 用户壁垒
1. **搜索习惯**：越用越准（个性化排序）
2. **数据积累**：历史搜索、收藏、标签
3. **工作流集成**：快捷键、菜单栏、轨道
4. **信任建立**：隐私安全承诺

### 市场壁垒
1. **细分定位**：专注个人搜索，不做企业
2. **价格优势**：一次买断，比订阅便宜
3. **口碑传播**：满意用户主动推荐
