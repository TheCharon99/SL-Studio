一、如何添加新项目

1 准备项目图片
  • 在项目文件夹中准备图片：cover.jpg（封面）+ 1.jpg 到 7.jpg（详情）
  • 图片格式：JPG，建议尺寸：1920×1080 像素
  • 图片大小：单张不超过 2MB
2 创建项目文件夹
  • 进入 images/ 文件夹
  • 新建文件夹，命名规则：项目名.jpg（例如：紫金府-现代简约.jpg）
  • 将项目图片放入文件夹
3 添加项目数据

打开 project-detail.html，找到第 20 行附近，添加项目信息：

// 在项目列表末尾添加新项目
{
    id: "紫金府-现代简约",           // 文件夹名称（英文或拼音）
    cover: "images/紫金府-现代简约.jpg/cover.jpg",
    images: [
        "images/紫金府-现代简约.jpg/1.jpg",
        "images/紫金府-现代简约.jpg/2.jpg",
        // ... 最多7张详情图
    ],
    title: "紫金府 · 现代简约风格",
    category: "私人公寓",               // 类型：私人公寓/私人豪宅/办公室/商业空间
    area: "120㎡",
    location: "上海金山",
    description: "项目描述文字..."
},
4 更新首页轮播图（可选）

如果需要首页轮播，打开 index.html，找到第 45 行，添加轮播图：

<img src="images/紫金府-现代简约.jpg/cover.jpg" alt="紫金府项目">
5 更新项目列表页

打开 projects.html，在对应分类下添加项目链接：

<li><a href="project-detail.html?project=紫金府-现代简约">紫金府 · 现代简约</a></li>

二、如何修改现有项目

1 修改项目信息

打开 project-detail.html，找到对应的 id，修改：title、category、area、description 等字段。

2 修改项目图片
  • 进入 images/项目文件夹/
  • 替换 cover.jpg 或 1.jpg 等图片
  • 保持文件名不变

三、如何更换项目图片

1 压缩图片（重要）

使用在线工具压缩图片：TinyPNG

  • 压缩前：2MB → 压缩后：<500KB
  • 保持画质清晰
2 替换图片
  • 进入对应项目文件夹
  • 删除旧图片，放入新图片
  • 保持文件名不变

六、如何上传更新到网站

⚠️ 重要：每次修改后都需要上传更新，否则网站不会显示新内容。
1 打开命令提示符
  • 按 Win + R，输入 cmd，回车
  • 进入网站文件夹：cd E:/portfolio/yier-studio
2 提交更改
git add .
git commit -m "添加新项目：紫金府"
3 上传到GitHub
git push origin main
4 等待更新
  • 等待 1-3 分钟
  • 访问 网站预览
  • 按 Ctrl+Shift+R 强制刷新浏览器

七、实用技巧

1. 常用快捷键

快捷键 功能
Ctrl + S 保存文件
Ctrl + Z 撤销上一步操作
Ctrl + F 在文件中搜索
Ctrl + Shift + R 强制刷新浏览器（清除缓存）

2. 常用命令速查

命令 功能
git status 查看有哪些文件被修改
git add . 添加所有修改的文件
git commit -m "说明" 提交更改并添加说明
git push 上传到GitHub

4. 常见问题

Q1: 网站不显示新图片？
A: 按 Ctrl+Shift+R 强制刷新，或清除浏览器缓存。
Q2: 图片太大加载慢？
A: 使用 TinyPNG 压缩图片。
Q3: 修改后网站没有变化？
A: 确保已执行 git push 命令上传到GitHub。
Q4: 如何查看修改记录？
A: 在命令行输入 git log 查看提交历史。
