# 懿贰设计网站 - 图片管理与项目增减教程

## 图片文件夹结构

```
images/
├── 项目-banner1.jpg ~ 项目-banner6.jpg   # 首页轮播图（6张）
├── 项目名1/
│   ├── cover.jpg                        # 项目封面图（首页/列表显示）
│   ├── 1.jpg ~ N.jpg                    # 项目详情图（可选，1-7张）
├── 项目名2/
│   ├── cover.jpg
│   └── 1.jpg ~ N.jpg
└── ...
```

**命名规则：**
- 文件夹名 = 网页显示的项目名（可用中文、空格、连字符）
- 封面图固定命名为 `cover.jpg`
- 详情图固定命名为 `1.jpg`, `2.jpg`, `3.jpg`... 从1开始连续编号
- 首页轮播图：`项目-banner1.jpg` ~ `项目-banner6.jpg`

## 一、修改项目图片

### 1. 修改项目封面图
```
步骤：
1. 将新图片复制到对应项目文件夹
2. 命名为 cover.jpg（覆盖原图）
3. 刷新浏览器即可看到更新

示例：修改"观唐府"封面
  复制新图片 → images/观唐府-意式风格/cover.jpg
```

### 2. 修改项目详情图
```
步骤：
1. 将新图片复制到对应项目文件夹
2. 按顺序命名为 1.jpg, 2.jpg, 3.jpg...
3. 删除不需要的图（直接删除文件即可）
4. 刷新浏览器

注意：
- 编号必须从1开始，连续递增
- 删除中间的图会导致序号不连续，请重新命名
- 如果少了图（如只有3张），命名为 1.jpg, 2.jpg, 3.jpg
```

### 3. 修改首页轮播图
```
步骤：
1. 将新图片复制到位
2. 命名为 项目-banner1.jpg ~ 项目-banner6.jpg
3. 刷新浏览器

注意：
- 必须保持6张，序号不能跳过
- 删除某张后需重命名后续图片填补空缺
```

## 二、新增项目

### 第一步：创建图片文件夹
```
在 images/ 下新建文件夹，命名规则：
- 中文名，无特殊符号
- 例如：images/新项目名称/
```

### 第二步：放置图片
```
新项目名称/
├── cover.jpg      ← 封面图（必须）
├── 1.jpg          ← 详情图1（可选）
├── 2.jpg          ← 详情图2（可选）
└── ...
```

### 第三步：更新 HTML 文件

#### 1. 更新 project-detail.html（第82-155行）

**在 `var projects = {` 中添加新条目：**
```javascript
'新项目名称': {
    name: '新项目名称',
    designer: '懿贰设计',
    location: '上海·金山',
    desc: '项目描述文字',
    images: ['images/新项目名称/cover.jpg', 'images/新项目名称/1.jpg', 'images/新项目名称/2.jpg']
},
```

**在 `var projectOrder = [` 中添加项目名：**
```javascript
var projectOrder = [
    '观唐府 · 意式风格','金山豪庭 · 中古奶油',
    // ... 其他项目 ...
    '新项目名称'   // ← 添加到这里
];
```

#### 2. 更新 projects.html（项目列表页）

**在 `<ul class="projects three-columns" id="filter_gallery">` 中添加新条目：**
```html
<li data-category="私人豪宅">
    <div class="projects-thumb">
        <div class="recent-project-details">
            <a href="project-detail.html?project=新项目名称">
                <img width="210" height="150" alt="新项目名称" src="images/新项目名称/cover.jpg" />
                <div class="thumb-cover" style="top:-137px;"><div class="thumb-more"></div></div>
            </a>
            <h5>新项目名称</h5>
        </div>
    </div>
</li>
```

**注意：**
- `data-category` 分类可选：`私人豪宅`、`私人公寓`、`办公室`、`商业空间`
- `href` 中的 project 参数必须与 `project-detail.html` 中的 key 完全一致

#### 3. 更新 index.html（首页，可选）

**在"最新项目"区域添加新条目：**
```html
<li style="text-align:center">
    <div class="projects-thumb">
        <div class="recent-project-details">
            <a href="project-detail.html?project=新项目名称">
                <img width="210" height="150" alt="新项目名称" src="images/新项目名称/cover.jpg" />
                <div class="thumb-cover" style="top:-137px;"><div class="thumb-more"></div></div>
            </a>
            <h5>新项目名称</h5>
        </div>
    </div>
</li>
```

## 三、删除项目

### 第一步：删除图片文件夹
```
删除 images/新项目名称/ 整个文件夹
```

### 第二步：更新 project-detail.html
```
1. 删除对应的项目条目（从 var projects 中）
2. 从 projectOrder 数组中移除对应的项目名
```

### 第三步：更新 projects.html
```
删除对应的 <li>...</li> 块
```

### 第四步：更新 index.html（如引用）
```
删除对应的 <li>...</li> 块
```

## 四、修改首页轮播图

### 替换轮播图
```
步骤：
1. 将新图片复制到 images/
2. 命名为 项目-banner1.jpg ~ 项目-banner6.jpg
3. 更新 index.html 中的 alt 描述文字
```

### index.html 轮播图区域（第46-55行）
```html
<div class="home-slider" id="slider">
    <img class="slide active" src="images/项目-banner1.jpg" alt="图片描述1" />
    <img class="slide" src="images/项目-banner2.jpg" alt="图片描述2" />
    <img class="slide" src="images/项目-banner3.jpg" alt="图片描述3" />
    <img class="slide" src="images/项目-banner4.jpg" alt="图片描述4" />
    <img class="slide" src="images/项目-banner5.jpg" alt="图片描述5" />
    <img class="slide" src="images/项目-banner6.jpg" alt="图片描述6" />
    <a href="#" class="slider-nav prev" aria-label="上一张">‹</a>
    <a href="#" class="slider-nav next" aria-label="下一张">›</a>
</div>
```

## 五、常用操作速查表

| 操作 | 修改文件 |
|------|----------|
| 修改封面图 | `images/项目名/cover.jpg` |
| 修改详情图 | `images/项目名/1.jpg ~ N.jpg` |
| 新增项目 | 3个HTML + 新建文件夹 |
| 删除项目 | 3个HTML + 删除文件夹 |
| 修改轮播图 | `images/项目-banner*.jpg` + index.html |

---

## 六、注意事项

1. **文件夹名必须与 HTML 中的项目 key 完全一致**（区分大小写）
2. **图片编号必须从1开始连续**，不能跳号
3. **HTML 中的 `?project=项目名` 必须与 project-detail.html 中的 key 一致**
4. **删除图片后记得更新 HTML**，否则会显示空白
5. **轮播图必须是6张**，序号不能跳过
